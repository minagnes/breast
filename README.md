# 유방영상의학과 근무 스케줄 생성기 (breast)

매달 근무 스케줄을 자동으로 만들어 주는 프로그램입니다.
연도·월과 각자의 휴가/학회/출장 일정만 넣으면, 규칙에 맞춘 엑셀 스케줄이 나옵니다.

프로그래밍을 몰라도 아래 순서만 따라 하면 됩니다.

---

## 0. 설치 없이 웹으로 바로 쓰기 (팀 동료 추천)

아래 주소로 접속하면 **아무것도 설치하지 않고** 브라우저에서 바로 스케줄을 만들 수 있습니다.

👉 **https://breast-snztpbfhgbaq2tvwvewnbi.streamlit.app/**

> 접속하면 로그인(인증) 화면이 먼저 뜹니다 — 근무자 정보 보호를 위해 **허가된 사람만** 볼 수 있도록 비공개로 열려 있습니다. (초대가 필요하면 저장소 관리자에게 문의하세요.)

**사용 순서 (웹):**
1. 연도·월을 고르고 **[휴가 입력표 생성]** → **[휴가 입력표 다운로드]** 로 엑셀을 받습니다.
2. 받은 엑셀을 열어 각자의 휴가·학회·출장을 칸에 입력(드롭다운 선택 가능)하고 저장합니다.
3. **2단계**에 그 파일을 업로드하고 **[스케줄 생성]** → **[완성된 스케줄 다운로드]**.
   - 완성 파일은 **브라우저의 다운로드 폴더**에 저장됩니다.

> 아래 1~5번은 내 컴퓨터에서 직접 돌리고 싶은 분(개발/수정)을 위한 안내입니다.

## 1. 폴더 구조

```
schedule/
├── src/                       ← 프로그램 코드
│   ├── schedule_core.py       ← ★ 배정 규칙·스케줄 엔진 (규칙은 여기 한 곳에서만 고침)
│   ├── generate_schedule.py   ← 터미널(검은 화면)에서 실행
│   └── streamlit_app.py       ← 웹 브라우저에서 실행 (같은 기능)
├── docs/                      ← 규정 문서(SoT). ⚠ 개인정보라 GitHub에 안 올림
│   └── 스케줄_배정_규정.docx
├── outputs/                   ← ★ 만들어진 엑셀이 저장되는 폴더. ⚠ 개인정보라 GitHub에 안 올림
├── requirements.txt           ← 필요한 부품 목록
├── README.md                  ← 지금 읽고 있는 설명서
├── CLAUDE.md                  ← Claude Code용 프로젝트 지도
└── .gitignore                 ← GitHub에 올리지 않을 파일 목록(자동 처리)
```

> - **규칙을 바꾸려면** `src/schedule_core.py` **한 곳만** 고치면 됩니다(터미널·웹 둘 다 반영). 규칙을 바꾸면 `docs/`의 규정 문서도 함께 고쳐 주세요.
> - **결과물(스케줄)과 규정 문서에는 근무자 정보가 들어 있어** `outputs/`·`docs/` 는 GitHub에 올라가지 않습니다(내 컴퓨터에만 남습니다).

## 2. 설치법 (최초 한 번만)

터미널(맥: 터미널 앱 / 윈도우: 명령 프롬프트)을 열고, 이 폴더 안에서 아래를 순서대로 입력합니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> - 첫 줄: 이 프로그램 전용 공간(.venv)을 만듭니다.
> - 둘째 줄: 그 공간을 켭니다. (윈도우는 `.venv\Scripts\activate`)
> - 셋째 줄: 필요한 부품(streamlit, openpyxl, holidays)을 설치합니다.

설치가 끝나면 다음부터는 `source .venv/bin/activate` 한 줄만 하면 됩니다.

## 3. 실행법

### 방법 A. 터미널에서 실행

```bash
python src/generate_schedule.py
```

1. 연도와 월을 입력합니다. (예: 2026 / 9)
2. 화면에 **[휴가 입력표]** 라벨과 함께 엑셀 파일의 전체 경로가 나옵니다.
3. 그 경로의 엑셀을 열어 각자의 휴가·학회·출장을 입력하고,
   **같은 위치에 그대로 저장**합니다. (다른 이름/폴더로 저장하면 프로그램이 못 읽습니다.)
4. 터미널로 돌아와 `Y` 를 누릅니다.
5. 완성된 스케줄이 만들어지고, **[완성 스케줄]** 경로가 화면에 표시됩니다.

### 방법 B. 웹 브라우저에서 실행

```bash
python -m streamlit run src/streamlit_app.py
```

- 브라우저 화면에서 버튼을 눌러 휴가 입력표를 내려받고,
  작성한 파일을 업로드하면 완성 스케줄을 다운로드할 수 있습니다.
- 다운로드한 파일은 **브라우저의 다운로드 폴더**에 저장됩니다.

---

## 4. 결과물은 어디에 저장되나요?

- **터미널(방법 A)로 만든 파일** → 프로젝트 루트의 `outputs/` 폴더 (실행 중 전체 경로가 화면에 표시됩니다)
- **웹(방법 B)으로 만든 파일** → 사용하는 브라우저의 다운로드 폴더

무엇을 했는지 한눈에 알 수 있도록, 메시지 맨 앞에 아래 표시를 붙입니다.

## 6. 팀 협업 규칙 (브랜치)

여러 명이 함께 고칠 때 서로 꼬이지 않도록 아래를 지킵니다.

- **`main` 브랜치**: 항상 정상 작동하는 최신본. 배포된 웹사이트가 이 브랜치를 따라갑니다. **여기에 직접 커밋하지 말 것.**
- **작업용 브랜치**: 아래처럼 `종류/설명` 형태로 새로 파서 작업하고, GitHub에서 Pull Request(PR)로 `main`에 합칩니다.

| 브랜치 이름 예시 | 언제 |
|------------------|------|
| `추가/10월-스케줄` 또는 `feat/oct-schedule` | 새 기능 |
| `수정/저장경로-안내` 또는 `fix/save-path-msg` | 기존 수정 |
| `문서/readme-보완` 또는 `docs/readme` | 문서만 |

> 규칙(예: K4 배정)을 바꿀 때는 **`src/schedule_core.py` 한 곳**만 고치고, `docs/`의 규정 문서도 함께 갱신하세요. (자세한 건 `CLAUDE.md` 참고)

## ⚠ 개인정보 주의

- `docs/`(규정 문서)와 `outputs/`(실제 스케줄)에는 **근무자 정보**가 들어 있어 GitHub에 올라가지 않도록 설정돼 있습니다(`.gitignore`).
- 실제 근무자 이름이 든 엑셀을 저장소에 **커밋하지 마세요.** 배포 사이트도 로그인한 사람만 접근할 수 있게 비공개로 두세요.
